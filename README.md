# Mnemo Mockup

Interactive quiz and voucher wallet web app built with Next.js, Tailwind CSS, and Motion.

## Naming

- **Mnemo** is the website and product name.
- **Hippome** is the AI avatar / study buddy character only. Never use Hippome for the website.

## Running Locally

```powershell
cd mockup
pnpm install
pnpm dev
```
